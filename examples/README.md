# 完整示例：资料库按收藏状态筛选

本目录是虚构练习，不含真实客户、订单、企业联系人、内部系统地址或实际运行结果。“已确认”只表示练习资料中设定的规则，不是用户对真实产品的批准。

1. [输入材料](source-notes.md)：完整的虚构需求与模拟沟通结论。
2. [调用提示](usage-prompt.md)：附加输入材料后复制使用。
3. [示例PRD](example-prd.md)：五章正文，展示正常、无结果、失败与权限边界。
4. [澄清示例](clarification-example.md)：材料冲突时应先问清什么。

本例不涉及费用计算、历史迁移、灰度开关或新增告警，因此没有为了模板齐全增加这些内容。示例流程图使用 Mermaid；无法预览 Mermaid 的工具仍可阅读对应文字步骤。

示例用于解释预期输出，并非对所有助手进行过独立生成测试；验收结果全部保留未执行。
