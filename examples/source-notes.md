# 虚构输入材料：资料库按收藏状态筛选

以下全部为公开演示的虚构设定，没有真实企业数据或实际审批。模拟产品团队已确认如下规则。

## 当前情况与目标

团队资料库已有收藏和取消收藏能力，列表能显示当前用户是否收藏，但没有收藏筛选。希望增加筛选，减少在全部资料中逐条查找；没有提供业务量、耗时或量化收益。

## 本次范围与规则

1. 在资料列表增加“收藏状态”，提供“全部”“已收藏”“未收藏”三个选项。每次进入默认“全部”，不记住上一次选择；清空筛选回到“全部”。
2. 收藏状态以当前登录用户为准。只查询其原本有权限访问的资料，前后端均保留既有权限校验，筛选不扩大可见范围。
3. 改变或清空筛选后回到第一页；每页条数和排序沿用列表现有设置。本次不修改收藏/取消收藏、排序、每页条数或权限配置。
4. 前后端只接受三个合法状态。非法值拒绝本次筛选，提示“请选择有效的收藏状态”，不执行资料查询，不静默改成全部。
5. 查询成功但无符合条件资料时，显示“暂无符合条件的资料”。
6. 查询失败时，保留用户选择，不显示上一次的列表，展示“加载失败，请重试”和既有重试入口；不得当作无数据，也不自动重试。用户点击重试时使用当前选择。
7. 查询进行中暂时禁用收藏筛选；请求结束后恢复可选，避免连续切换产生多个筛选请求。
8. 本次不新增通知、数据迁移、独立配置页、开关或监控告警。若筛选结果错误或出现越权资料，停止发布或按已有版本回退流程恢复旧版列表，不修改已有收藏数据。

|---|---|---|

## 模拟沟通结论

模拟产品团队确认了三个选项、默认行为、成功无结果与失败的不同处理，要求保留既有权限和收藏功能。示例测试角色按这些规则执行验收，所有用例尚未运行。没有具体人员姓名、研发排期或上线日期，不增加这些事实。
