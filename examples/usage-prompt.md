# 调用提示

先向助手附加本目录的 `source-notes.md`，再复制以下内容：

```text
请使用 $prd-generator，根据本次附加的 source-notes.md 生成实施型 PRD。
这是虚构演示，按材料中已确认的设定整理，不补充人员、排期、收益或实测数据。
保留五章结构，写清三种收藏状态、权限、翻页、成功无结果、加载失败和手动重试。
裁剪本次没有的计算、迁移、开关、告警等模块，验收结果写未执行。
输出到当前工作区 outputs/资料库收藏筛选/。
```

若要仅评审，可将第一句改为“请使用 $prd-generator，对照输入材料评审现有 PRD，列出影响实施或验收的问题，先不要改写原文”。
